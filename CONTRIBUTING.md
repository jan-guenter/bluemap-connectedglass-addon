# Contributing

Keep contributions inside the exact profile and licensing boundary documented
in README and `AGENTS.md`. Do not copy or adapt Connected Glass or Fusion code or
assets. Runtime-installed ARR resources may be parsed only through the bounded
metadata/behavior contract.

Changes to the artifact tuple, allowlist, resource closure, predicate schema,
selector tables, BlueMap ABI, or publication identity require regenerated
evidence, tests, documentation, and a version increase through a pull request.
Pixel-only resource-pack overrides must remain supported.

Use LF endings, preserve SPDX/attribution headers, update deterministic outputs
through their generators, and run the single focused local gate from README.
Do not commit build output or third-party inputs.
