# Security policy

This technically staged and owner-accepted alpha candidate has no supported
production version. The 2026-08-16 acceptance authorizes only immutable
`0.1.0-alpha.1` prerelease publication; neither it nor the disposable-host pass
authorizes production deployment or creates a production-support commitment.
Report suspected resource-parser denial of service, namespace collision,
archive traversal, activation bypass, unsafe fallback, or
publication-boundary defects privately to the repository owner before public
disclosure.

The parser is intentionally bounded to exact artifacts, a fixed 737-path
closure, a separate three-path host-model ABI, 256 KiB per model, five
predicate-node levels and 14 nodes per connection predicate, exact namespaces,
and a fixed predicate vocabulary. Unknown or malformed input must deactivate
the route or atomically use stock rendering; it must never become a broader
interpreter.

Do not attach proprietary JARs, production maps, server logs, credentials,
world data, player data, or resource-pack assets to public reports.
